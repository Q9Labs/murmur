Arabic UI, without mixing it with speech

Murmur gains a Git-owned MSA Arabic shell. The UI locale controls app copy, digits, and layout direction; source and target speech languages keep their own rules.

Read the executor spec

The app shell is English and left-to-right. Arabic direction is limited to transcript text.

The shell switches between English and MSA Arabic. Copy, digits, layout, and accessibility update together.

Speech languages stay independent, so an English shell can show Arabic captions and an Arabic shell can show English captions.

English is the stable default. Murmur does not guess from the device or the active translation pair.

UI locale

Owns buttons, messages, accessibility labels, Arabic digits, and app layout direction.

Speech language

Owns live translation and transcript writing direction. It does not change the shell.

 Future ar-SA and ar-AE are separate switcher languages and catalogs. The runtime never folds them into ar.

The active language is visible in Settings. This illustrative preview shows the replacement view inside the same sheet, so native platforms never stack a second modal.
