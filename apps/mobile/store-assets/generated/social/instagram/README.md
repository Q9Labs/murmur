# Murmur Instagram Launch Set

These 1080 × 1920 static story and Reel-cover assets are generated from verified Murmur product captures. Rebuild them with:

```sh
node tooling/scripts/build-store-screenshots.mjs
```

Use the assets as two separate concepts:

1. `02-conference-talk-story.png` targets attendees following talks, lectures, and workshops.
2. `04-how-murmur-works-story.png` explains the choose, listen, read flow.

Pair each static asset with a matching store product page or listing when those live pages exist. Do not run Arabic-language copy until the whole app interface and support path have a verified Arabic localization.

For motion variants, record a real current-build caption session vertically, keep the Murmur screen readable, add spoken audio and burned-in subtitles, and place the main message inside the central safe area. Do not animate or fabricate translation output.
