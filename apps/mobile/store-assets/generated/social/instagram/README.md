# Murmur Instagram Launch Set

These 1080 × 1920 static story and Reel-cover assets are generated from verified Murmur product captures. Rebuild them with:

```sh
node tooling/scripts/build-store-screenshots.mjs
```

Use the assets as four separate concepts:

1. `01-travel-guide-story.png` targets travelers following guides and demonstrations.
2. `02-conference-talk-story.png` targets attendees following talks, lectures, and workshops.
3. `03-accountless-privacy-story.png` leads with no sign-up and no saved transcript history.
4. `04-how-murmur-works-story.png` explains the choose, listen, read flow.

Keep traveler and talk concepts in separate ad sets. Pair each static asset with a matching store product page or listing when those live pages exist. Do not run Arabic-language copy until the whole app interface and support path have a verified Arabic localization.

For motion variants, record a real current-build caption session vertically, keep the Murmur screen readable, add spoken audio and burned-in subtitles, and place the main message inside the central safe area. Do not animate or fabricate translation output.
